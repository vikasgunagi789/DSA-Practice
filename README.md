# Data Structures and Algorithms in C

The Algorithms Contains the program which are done in college 

This repository contains implementations of fundamental Design and Analysis of Algorithms (DAA) and Data Structures concepts using the C programming language.

## Algorithms Implemented

### Graph Algorithms

* Kruskal's Algorithm
* Prim's Algorithm
* Dijkstra's Shortest Path Algorithm
* Floyd's All-Pairs Shortest Path Algorithm
* Warshall's Transitive Closure Algorithm
* Topological Ordering

### Dynamic Programming and Backtracking

* 0/1 Knapsack Problem
* Subset Sum Problem
* N-Queen Problem

### Sorting Algorithms

* Selection Sort
* Quick Sort
* Merge Sort

### Additional Programs

* Knapsack Problem Implementation
